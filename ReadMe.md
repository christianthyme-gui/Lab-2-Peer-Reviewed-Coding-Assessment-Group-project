# Shopping List Application

This is a simple Swing app that allows users to create and manage a shopping lists. Users can add items, remove items, and mark items as purchased.

The program also have a menu bar and a filter bar.

## Requirements
- Java Development Kit (JDK) 8 or later
- No external libraries or other build tools needed.

## Components
- ShoppingList.java - Manages shopping items, purhcased status, and filter functionality.
- Main.java - Application entry point. Creates shopping list window and JMenuBar.
